# Institute of Digital Risk (IDR) – Internship Assignment

This repository contains my submission for the **Frontend Internship Assignment**.
The task was to design a **logo** and build a **responsive homepage** for a fictional institute called **Institute of Digital Risk (IDR)**.

## Project Overview

The goal of this assignment is to create a clean and minimal digital presence for an institute focused on **digital risk, cybersecurity, and AI governance**.

The project includes:

* A **logo design** for the Institute of Digital Risk
* A **single-page responsive homepage**
* Clean **HTML5 semantic structure**
* Responsive layout using **CSS Flexbox/Grid**
* Smooth scrolling navigation
* Simple interactive elements using **vanilla JavaScript**

---

## Logo Design

The logo consists of a **geometric form of a cube** that is a combination of colors such as **orange, black, and white**. The cube represents the **systems and architecture used in digital risk, cybersecurity, and AI governance**.

The logo is **simple and minimalistic**. It is a representation of a **3D object with subtle depth**, which reflects the institute’s dedication to **simplicity, discipline, and structured learning**. The design also represents the institute’s objective of **reducing distractions and emphasizing the quality and correctness of its curriculum**.

The geometric cube also represents the institute’s commitment to **working with the latest technologies and tools** while maintaining a **robust and structured learning environment** for its students.

### Design Elements

* **Primary colors:** Orange, Black, White  
* **Style:** Minimal, professional, technology-focused  
* **Variants included:**

  * Icon-only version
  * Icon + text ("Institute of Digital Risk")

## Homepage Features

The homepage is a **single-page responsive layout** that includes the following sections:

### 1. Hero Section

* Mission headline
* Brief description of IDR
* Call-to-action buttons

### 2. About IDR

Overview of the institute and its focus on training and deploying digital risk professionals.

### 3. Service Pillars

Three core pillars of the institute presented as cards:

* **Academy** – Training programs and bootcamps
* **Innovation & Incubation** – AI governance and risk model development
* **Advisory Services** – Implementation of cybersecurity frameworks

### 4. Community

Information about the target audience:

* Students
* Early-career professionals
* Industry practitioners

### 5. Contact / Register Interest

Simple contact form for users to submit their interest.

## Technical Implementation

The project is built using **vanilla web technologies**:

* **HTML5** (semantic elements)
* **CSS3** (Flexbox/Grid + responsive design)
* **JavaScript** (basic interactivity)

### Key Features

* Responsive layout (desktop and mobile)
* Sticky navigation bar
* Smooth scrolling navigation
* Accessible color contrast
* Hover states for buttons and links
